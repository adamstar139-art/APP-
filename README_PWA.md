# تحويل التطبيق إلى تطبيق جوال قابل للتثبيت (PWA)

هذه الحزمة تحوّل نظام تحضير متوسطة الثغر النموذجية إلى تطبيق يُثبَّت على الشاشة الرئيسية للجوال ويفتح بملء الشاشة كأنه تطبيق حقيقي — يعمل على أندرويد والآيفون معًا.

## محتويات الحزمة

- `thaghr_attendance_app.py` — التطبيق (مع إضافة تهيئة PWA).
- `logo_data.py` — الشعار المضمّن.
- `static/manifest.json` — ملف تعريف التطبيق (الاسم، الأيقونة، فتح بملء الشاشة).
- `static/icon-192.png` و `static/icon-512.png` — أيقونات التطبيق.
- `static/apple-touch-icon.png` — أيقونة الآيفون.
- `.streamlit/config.toml` — إعداد يفعّل تقديم ملفات PWA.

> ملاحظة: إن كان لديك ملف `.streamlit/config.toml` سابق، ادمج محتواه مع هذا الملف (لا تحذف إعداداتك)، والأهم إبقاء السطر:
> `enableStaticServing = true`

## خطوات النشر (مرة واحدة)

1. ارفع كل هذه الملفات (مع الحفاظ على بنية المجلدات: `static/` و `.streamlit/`) إلى مستودع GitHub.
2. أضف أسرار Supabase في إعدادات التطبيق على المنصة (Secrets)، كما تفعل عادةً.
3. انشر التطبيق على Streamlit Community Cloud (مجاني). ستحصل على رابط دائم مثل:
   `https://اسم-تطبيقك.streamlit.app`
4. افتح الرابط في المتصفح للتأكد من عمله.

## كيف يثبّته المعلم على جواله

### أندرويد (Chrome)
1. افتح رابط التطبيق في متصفح Chrome.
2. اضغط قائمة النقاط الثلاث (⋮) أعلى اليمين.
3. اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
4. ستظهر أيقونة باسم «حضور الثغر» وشعار المدرسة، تفتح بملء الشاشة.

### آيفون / آيباد (Safari)
1. افتح رابط التطبيق في متصفح Safari (ليس Chrome).
2. اضغط زر المشاركة (المربع والسهم للأعلى).
3. اختر «إضافة إلى الشاشة الرئيسية».
4. اضغط «إضافة» — ستظهر الأيقونة على الشاشة الرئيسية.

## ملاحظات مهمة

- التطبيق يحتاج اتصال إنترنت لأنه يتصل بخادم Streamlit وقاعدة بيانات Supabase.
- عند أي تحديث تعمله على التطبيق، يصل للجميع تلقائيًا دون إعادة تثبيت.
- يعمل الرابط نفسه على كل الأجهزة (أندرويد + آيفون + حاسوب).
